# strata-utils

Small tools for the local Strata server (`strata.service`).

| Path | What |
| --- | --- |
| [strata-model](strata-model) | Choose which installed Strata model size `strata.service` serves. Installed as `~/.local/bin/strata-model` (a symlink to this file) |

GPU sharing with ComfyUI is vhotseat's job, not these tools': see
`~/Projects/vhotseat` ([github.com/wandermyz/vhotseat](https://github.com/wandermyz/vhotseat)).
